
# Quicklist

Projeto desenvolvido para o desafio prático do módulo de HTML, CSS e JavaScript da Rocketseat. 

A aplicação é uma lista de compras simples e responsiva, onde customizei a interface com cores inspiradas no Brasil.

## Funcionalidades

- Adicionar novos itens (com validação para não enviar campo vazio)
- Marcar e desmarcar itens como concluídos
- Remover itens da lista
- Aviso visual (toast) ao deletar um item
- Layout adaptável para celular e desktop

## Tecnologias

- HTML5
- CSS3 (Flexbox e variáveis)
- JavaScript (Manipulação de DOM)
